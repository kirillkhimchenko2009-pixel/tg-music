# GitHub Pages — хостинг статики Vibe v2

Клиент v2 (`frontend/dist`) можно раздавать с GitHub Pages, а API оставить на
туннеле машины. После этого мини-апп открывается со стабильного URL, а свежая
сборка деплоится командой одной строкой.

## 1. Публичный репозиторий

1. Зарегистрируйся/залогинься на github.com и создай НОВЫЙ публичный репозиторий,
   например `vibe-music-web` (только README не нужен).
2. Пришли мне имя репозитория (или сразу URL вида `https://github.com/<юзер>/<репо>.git`,
   плюс запиши свои логин/токен локально — токен нужен to push).

## 2. Что произойдёт дальше (сделаю я)

- в `frontend/` добавлю `deploy.ps1`: `npm run build` → копия `dist` в ветку `gh-pages` → push;
- в BotFather меню-кнопка получит URL `https://<юзер>.github.io/vibe-music-web/?api=https://<туннель>`
  — это уже делает вотчер сокета через файл `data/webapp_url.txt` (авто).

## Параметры уже готовы

- `vite.config.js` имеет `base: './'` — сборка работает из любого подкаталога Pages;
- `src/api.js` читает `?api=...` из адреса страницы — незачем ничего пересобирать
  при смене туннеля (API URL передаётся в адресе, который бот ставит в кнопку);
- для входа из обычного браузера остаётся `/code` в боте.
